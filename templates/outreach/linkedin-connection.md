# LinkedIn Connection Request — structure (max 300 characters)

> Structure only — the Networking agent writes each message fresh.
> Never send templated text.

Components, in order:
1. Shared context (their post, the role, a mutual connection, their product)
2. Reason for connecting (one clause, specific)
3. Professional interest (no ask in the first message)

Example shape (do not reuse verbatim):
"Hi <Name> — saw <Company> is hiring an <Role> and I've been building exactly
this kind of n8n + Claude automation for <domain>. Would be glad to connect."
