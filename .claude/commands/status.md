description: Pipeline dashboard — every opportunity by state, metrics, and what needs attention

Read `memory/applications.json`, `memory/metrics.json`, and
`memory/interviews.json`, then show the pipeline dashboard:

1. **Counts per state** (DISCOVERED → … → OFFER/REJECTED)
2. **Active applications table**: Company | Role | State | Tier | Priority |
   Days in state | Next action
3. **Needs attention**: items WAITING FOR APPROVAL, follow-ups overdue,
   opportunities going stale (>7 days without progress), upcoming interviews
4. **Metrics**: applications this week, response rate, interview rate,
   average time per application
5. **One-line recommendation** for the next best action

Keep it scannable — this is a dashboard, not a report.
