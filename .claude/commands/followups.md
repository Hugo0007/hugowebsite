Run the follow-up sweep:

1. Read every active application's `follow-up.md` / `networking.md` schedule
   and `memory/recruiters.json`.
2. List everything due today or overdue: SUBMITTED applications with no
   response at day 3/7/14 checkpoints, recruiter threads awaiting a nudge,
   post-interview thank-you notes not yet sent.
3. For each due item, launch **networking** to draft the message (short,
   specific, value-adding — per its rules). Present all drafts for approval.
   **Never mark anything as sent — the user sends.**
4. After the user confirms what was sent, update `memory/recruiters.json`
   and the application records with the touchpoint and next checkpoint date.
5. Anything past day 14 with no response: recommend archiving, and on
   confirmation set the application status accordingly with a lesson recorded
   for the Learning Analyst.
