description: Weekly intelligence report — what's working, what to change, next week's plan
---

Run the weekly review:

1. Launch the **learning** agent to analyze the week: applications,
   response/interview/offer rates, top-performing resume versions and
   messages, best sources, patterns, and lessons →
   `reports/weekly/<yyyy-Www>.md`.
2. Launch the **chief-of-staff** agent to turn the findings into next week's
   plan: capacity allocation across applying / demos / networking / learning,
   and the top 3 priorities.
3. Present both: an honest scoreboard first (no vanity metrics — if response
   rate is low, say so and diagnose), then the plan.
4. If the learning agent proposed config changes (scoring weights, source
   priorities), present them as diffs for approval before editing anything
   in `config/`.
5. Commit the report to git.
